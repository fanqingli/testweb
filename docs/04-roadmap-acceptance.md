# 04 实施路径、验收与风险

> 工期为按一个 6–8 人小组的粗估，仅用于排序与相对比较；指标数值均为建议值，需在阶段 0 测得基线后定稿。

## 1. 分阶段实施

原方案 11.1 的顺序是“先原型含 AI，再核心流程，再识别能力”。修订后的顺序遵循两条规则：**每个阶段结束都能独立投入使用**；**不确定性最大的事情最先验证、最后依赖**。

| 阶段 | 目标 | 主要交付 | 完成判据 | 粗估 |
|---|---|---|---|---|
| 0 验证与基线 | 把最大的不确定性变成数据 | 样本库与标注集；识别路线比选；私有模型在 Pi 下的任务集评测；与既有指标系统的接口确认；指标定稿 | §2 清单全部有结论 | 3–4 周 |
| 1 协同闭环（零 AI） | 不依赖任何识别能力即可完成一次完整采集 | 计划、批次、任务、明细；L1 在线表单；L2 系统模板下发与回收；指标级分派、批注答疑；三档确认中的 A 档与逐项确认；业务复核、签署、入库发件箱与对账；事件流与哈希链；基础看板与催办 | 一个真实批次全流程走通并入库；每个入库值可导出溯源包 | 8–10 周 |
| 2 原生文件识别 | 存量 Excel、Word、电子 PDF 可预填 | IR 制品；多态锚点与证据渲染；通用规则路径；校验规则库；指针式候选；B、C 档确认界面；纠错回流 | 原生文件指标达到 §3 门槛；人工修改可回流为样本 | 8–10 周 |
| 3 Agent 层 | 用 Agent 扩大覆盖、降低运营成本 | Agent 调度器、运行器、MCP 工具服务、守卫扩展、审批队列、AI 运行记录；场景 G1、G2、G3；能力包规格、回归、灰度、审批发布 | G1、G2 达到 §3 门槛；所有 Agent 运行可回放 | 6–8 周 |
| 4 扫描件与管理增强 | 覆盖扫描件；提升管理效率 | 双引擎 OCR 与数字专项校验；关键指标盲录；场景 G5、G6、G7；批量操作、处置工作台、数据成果出口、变更单、更正单 | 扫描件达到 §3 门槛；在途处置与成果出口可用 | 8–10 周 |
| 5 运营优化 | 稳定运行并持续降本 | 事后抽检常态化；通道结构与差错率月报；场景 G4、G8、G9；性能与容量优化 | 连续两个采集周期入库差错率达标 | 持续 |

阶段 1 与阶段 2 的解析基础工作可以并行；阶段 3 依赖阶段 2 的 IR 与锚点。若阶段 0 发现私有模型能力不足以支撑 G2，则阶段 3 只做 G1（构建期用能力更强的模型或由人辅助）和 G3，G2 保持为“规则路径加人工”，整体方案仍然成立——这正是把确定性通道放在前面的原因。

## 2. 阶段 0 验证清单

| 验证项 | 方法 | 产出 |
|---|---|---|
| 样本库 | 向 5–10 家典型单位收集近两期真实材料，覆盖 Excel、Word、电子 PDF、扫描件；脱敏后入库，限定访问 | 不少于 200 份文件；按版式聚类的清单 |
| 标注集 | 两人独立标注“明细 → 正确锚点与值”，不一致处仲裁 | 不少于 3000 个标注明细；标注规范 |
| 通道可行性 | 调研各单位是否接受系统模板、是否有可对接系统 | 各通道预计占比 |
| 原生解析 | 候选解析库在样本上的表格与表头恢复比选 | 选型结论与结构恢复基线 |
| OCR | 至少两套引擎在扫描样本上的数字级准确率 | 选型结论；数字误识类型分布 |
| 私有模型加 Pi | 用 G1、G2 任务集评测现场可用模型 | 完成率、正确率、耗时；Agent 承担范围的结论 |
| Pi 接入细节 | 03 §2 所列四项未核实事项 | 启动参数与部署规格定稿 |
| 既有系统接口 | 指标版本同步、入库写回的接口形式、幂等与回执能力 | 接口约定或文件交换方案 |
| 签署与时间戳 | 现场电子签章、时间戳服务能力与调用成本 | 签署介质与日摘要锚定方案 |
| 合规 | 国产化、许可证、数据分级、留存期限要求 | 选型约束清单 |

## 3. 验收指标（建议值）

### 3.1 质量

| 指标 | 测量方法 | 建议门槛 |
|---|---|---|
| 入库差错率 | 入库后独立抽检（02 §7.3） | 不高于 0.5%，关键指标为 0 |
| L2 模板导入正确率 | 标注集 | 100%（确定性，出现错误即缺陷） |
| B 档错误率 | 标注集与线上人工修改 | 不高于 0.5% |
| 原生文件已知版式（L3）预填正确率 | 标注集 | 不低于 99% |
| 原生文件陌生版式（L4）预填正确率 | 标注集，拒识不计入分母，另报覆盖率 | 正确率不低于 95%，覆盖率不低于 70% |
| 扫描件预填正确率 | 标注集，同上 | 正确率不低于 97%（经双引擎与校验过滤后），覆盖率按基线定 |
| 证据锚点正确率 | 抽检锚点是否指向取值位置 | 100%（指针式抽值下由机制保证） |
| IR 可复现 | 同一文件重复解析 | IR 摘要一致率 100% |

说明：衡量识别好坏的核心不是总体准确率，而是“系统说可信的那部分有多可信”（B 档错误率）和“最终入库错了多少”（入库差错率）。总体准确率不高可以靠拒识和人工兜住，B 档错误率高则会直接污染数据。

### 3.2 留痕与人工确认

| 指标 | 门槛 |
|---|---|
| 入库值溯源完整率（可导出完整溯源包） | 100% |
| 事件哈希链校验 | 任意时间段校验通过；人为篡改测试能被发现 |
| 无人工确认与复核签名而入库的值 | 0 |
| Agent 运行可回放率（保有会话文件与作业规格） | 100% |
| Agent 越权动作（未经审批产生副作用） | 0（以渗透与注入测试验证） |
| C 档确认时证据展示率 | 100% |

### 3.3 Agent

| 场景 | 指标 | 建议门槛 |
|---|---|---|
| G1 能力包编写 | 生成的能力包通过回归并经评审发布的比例 | 不低于 60%；其余由人修改后发布 |
| G2 候选定位 | 提交的首选候选正确率；“未找到”报告的准确性 | 不低于 90%；不得以猜测代替“未找到” |
| G3 校验诊断 | 诊断结论被经办人采纳的比例 | 不低于 70% |
| 全部 | 注入测试集下的越权成功次数 | 0 |

### 3.4 效率与性能

| 指标 | 建议门槛 |
|---|---|
| 单位经办人均办理时长 | 较现状下降不低于 40%（现状在阶段 0 测量） |
| 复核人单任务复核时长 | 较现状下降不低于 30% |
| 批次生成（1 万条明细） | 2 分钟内完成 |
| 原生文件解析（单文件，50 页或 20 个工作表以内）P95 | 30 秒 |
| 扫描件解析（20 页）P95 | 3 分钟 |
| 看板与列表查询 P95 | 2 秒 |
| 入库写回最终成功率（含重试） | 100%，对账零差异 |

## 4. 风险登记

| 风险 | 可能性 | 影响 | 应对 |
|---|---|---|---|
| 私有模型能力不足，Agent 任务完成率低 | 高 | G2 等场景不可用 | 阶段 0 先测；方案不依赖 Agent 成立；Agent 重心放在构建期（G1） |
| 填报单位不愿改用系统模板 | 中 | L2 占比低，识别压力大 | 模板可按单位现有报表样式定制；保留 L3、L4；以减少退回次数作为推广理由 |
| 扫描件质量差 | 高 | 识别正确率不达标 | 上传时做清晰度检测并提示重扫；关键指标盲录；鼓励提供电子版 |
| 人工确认走过场 | 高 | 错误带签名入库 | 三档确认、证据必看、盲录、事后抽检、按行为信号调整抽样 |
| 既有指标系统接口能力不足 | 中 | 入库与同步受阻 | 发件箱加对账；受控文件交换兜底（原方案已有） |
| 能力包数量膨胀、维护成本高 | 中 | 运营负担 | 路径匹配提高鲁棒性；指纹相似度监测；长期未命中的自动归档；G1 承担修复 |
| 校验规则误报多 | 中 | 用户忽略提醒 | 规则发布前在历史数据试跑；提醒必须附可操作的说明；定期清理低价值规则 |
| 留痕数据量增长 | 中 | 存储与查询成本 | 事件按月分区；会话文件与 IR 制品分级存储；留存期限按制度 |
| Pi 版本演进带来接口变化 | 中 | 接入代码失效 | 固定版本；适配层隔离；升级前重跑任务集 |
| 提示注入与数据越权 | 低到中 | 数据泄露或误操作 | 机制性防线（03 §9）加上线前注入测试 |

## 5. 需要决策的事项

在原方案 1.6 的评审事项之外，新增以下需业务方决定的问题：

| 事项 | 建议 | 不这样做的后果 |
|---|---|---|
| 是否推行系统模板（L2）作为主通道 | 推行，新指标集默认生成模板 | 长期依赖识别，确认工作量降不下来 |
| 关键指标清单及其确认强度 | 由业务部门圈定，启用盲录或双人确认 | 关键数据与普通数据同等对待，风险集中 |
| 可接受的入库差错率 | 普通指标 0.5%，关键指标 0 | 抽样量与确认档位无从设定 |
| 事后抽检由谁承担 | 业务部门内非原复核人，或内审岗位 | 没有独立的最终质量度量 |
| Agent 可提议的动作范围 | 初期仅催办与指定跟进人；延期等高风险动作暂不开放 | 审批负担或风险过大 |
| 构建期是否允许使用能力更强的模型 | 若制度允许，仅用于脱敏样本上的能力包编写 | G1 效果受限于现场模型 |
| Agent 运行记录的留存期限 | 与对应入库值的留存期限一致 | 事后无法解释 AI 建议 |
| 事件日摘要的锚定方式 | 使用现有电子签章或时间戳服务 | 留痕只能自证，无第三方背书 |
| 样本材料的使用授权 | 与填报单位约定样本可用于回归测试，脱敏、限域访问 | 回归集无法合规建立 |
