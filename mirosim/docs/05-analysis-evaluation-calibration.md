# 05 分析、评测与校准

## 1. 汇总

所有汇总都从反应表出发，按（版本 × 重复 × 模型族 × 分群）分组。

**分母。** 每个比例都注明分母是哪一个：

| 分母 | 含义 | 何时用 |
|---|---|---|
| 全体 | 抽到的所有人物，含未曝光与无效 | 自然曝光下的行为比例 |
| 被曝光者 | `exposed = true` | 内容本身的评价 |
| 注意到的人 | `noticed = true` | 评分均值 |
| 有效回答者 | 该题非 `dk`、非缺失 | 各量表题 |

`dk` 与缺失的比例本身是结果，单独列出，不并入中间档。

**代表性加权。** 分群 s 的权重为 `w_s = share_s / (n_s / N)`。每个汇总数字同时给出加权与不加权两种；两者差别大时，说明结论由被超额抽样的小群体主导，报告里指出。

**有效样本量。** 加权后按 `n_eff = (Σw)² / Σw²` 计算并列出。`n_eff` 小于 30 的分群只做定性描述，不报比例。

**研讨模式。** 沿用 v3.0 的分析模块，输入改为私下立场与公开发言（`docs/01` §4.2）。以下 §2–§4 主要针对群体反应与传播模式。

## 2. 版本之间的比较

同一个人物看了每一个版本，所以比较在人物内部做：

```text
对版本 A、B 与指标 y：
  d_i = y_i(B) − y_i(A)                 逐人物；先在各次重复内对 y 取均值
  D   = Σ w_i d_i / Σ w_i               加权平均的配对差
  区间：对人物做分层自助法（按分群分层，2000 次重抽），取 2.5% 与 97.5% 分位
```

- 量表题：y 为评分。
- 分类题与行为：对每个类别分别设 0/1 指标，同样做配对差。
- 重抽的单位是人物而不是单条反应：同一人物的多次重复不是独立观测。
- 自助法的随机数由 `seed` 派生，结果可复现。

**与噪声底比较。** 安慰剂与其原版本之间也按上面的办法算一个配对差及区间，记为噪声底。任何两个候选之间的差，须同时满足两条才报告为「有差别」：

1. 自己的 95% 区间不含零；
2. 差的绝对值大于噪声底区间的上界（取绝对值后的较大端点）。

不满足的写「无法区分」。这一条不通融：两个逐字相同的版本都能测出的差，不能当作发现。

**多重比较。** 版本多、指标多、分群多时，总会有几个「显著」的格子。规则：实验配置里的 `question` 对应的那个比较是主要比较，按上述标准判定；其余都是探索性的，在报告里另列并标明「探索性，需另行验证」。

**这里的区间是什么。** 它反映的是人物抽样与模型采样带来的波动，不是对真实人群的推断区间。报告里每一处区间旁边都带这句说明。把模拟人数加到一万，区间可以任意窄，而结论并不因此更接近现实——人数只应加到分群内 `n_eff` 够用为止。

## 3. 开放回答

`takeaway`、`inner_reaction`、`reasons`、`quote`、各开放题，按 `prompts/theme_coding.md` 编码成主题。产出：

| 产出 | 做法 |
|---|---|
| 主题占比 | 按版本、按分群的主题提及率；同样做配对差 |
| 误读清单 | `takeaway` 的主题中与原文要点不符的，逐条列出占比与原话 |
| 说出口与没说出口 | `inner_reaction` 与 `quote` 的主题分别统计；只在前者出现的主题单列 |
| 代表性原话 | 每个主题按分群各取一到两句。选取规则：离该主题的典型表述最近的，而不是最精彩的；由代码按相似度选，写入台账 |

所有引用的原话在报告中带人物编号与「模拟人物」标记，可回查到完整反应。

## 4. 异质性：差别出在谁身上

| 切法 | 用途 |
|---|---|
| 按分群 | 基本切法 |
| 按处境变量 | 收入档、从业年限、有无子女等 |
| 按性格变量 | 四条轴各分正、负、边界三组；五项特质各分低、中、高 |
| 按事前态度 | 品牌包：原本喜欢、无感、反感的人分开看 |

性格切法有一个附带用途：检验映射表。例如高制度信任的人物对政策的 `pol_trust_exec` 理应更高；若全无差别，说明那项特质没有起作用。这类检验的结果记入映射表的版本记录。

只报告在各次重复中方向一致的异质性。切得越细，偶然的差别越多，同样受 §2 的探索性规则约束。

## 5. 效度阶梯

| 等级 | 含义 | 证据 | 允许的结论 |
|---|---|---|---|
| L0 像 | 人物的反应读起来合情理，性格与卡上一致 | 入库质检通过；人工盲评；十二项失真指标在门槛内 | 定性发现：理由、顾虑、误读、可能出现的行为类型 |
| L1 稳 | 结论不随重跑、不随换模型而变；分得出好坏 | 重复间排序一致；安慰剂差异小；负对照通过；至少两个模型族排序一致 | 版本之间的排序；差别集中在哪些分群 |
| L2 方向对 | 在已知结果的历史案例上，排序和方向与现实一致 | 回测：同类场景不少于 5 个历史案例，方向命中率达到约定门槛 | 带方向的预判；可用于方案筛选 |
| L3 量级准 | 比例数字经现实数据校准，误差已知 | 与同题真实问卷或投放数据对照，分群层面的误差在约定范围内 | 带误差范围的比例估计 |

规则：

- 等级按「场景包 × 人群框架 × 人物模型」分别认定。政策包在某人群上到了 L2，不代表营销包也到了。
- 换人物模型后，等级退回 L1，重新认定。
- 每份报告的首页标明等级。报告生成器按等级裁剪内容：L0 不出排序表；L1 及以下的比例数字只出现在版本对比的图表里，并带「仅供比较，非预测值」的标注，摘要里不出现百分数。
- 清单的 `validity_level` 字段记录等级。

第 1 期交付时系统处于 L0，目标是在第 2 期达到 L1。L2 与 L3 取决于能否拿到现实数据，时间不由开发进度决定。

## 6. 校准

### 6.1 回测（走向 L2）

选取结果已知的历史案例：已经落地的政策及其后的反馈、已经投放的两版文案及其实际表现、已经发生的危机回应及其后的舆论走向。

```text
对每个案例：
  1  把当时的方案整理成刺激物（只用当时已公开的信息）
  2  人物的 as_of_date 设为事件之前；检索不到该日期之后的记忆
  3  照常跑实验，在看结果之前把预测写下来并封存（预登记）
  4  与实际结果对照：版本排序对不对、主要反对理由有没有出现、有没有漏掉的群体
```

沿用 v3.0 §11.4 的记录格式与「漏报比误报重要」的原则。

**一个绕不开的问题：模型可能已经知道结果。** 训练数据里若包含该事件的报道，回测就不是预测。对策：优先选模型训练截止日期之后的案例；选不到时，改用不知名的地方性或企业内部案例；并在回测记录里注明该案例是否可能被模型见过。被见过的案例不计入 L2 的认定。

### 6.2 对照真实数据（走向 L3）

最直接的办法是做一次小规模的真实问卷：把实验里的量表题原样拿去问真实受访者（每个关键分群几十到一百人），与模拟结果对照。

| 对照项 | 算法 |
|---|---|
| 均值偏差 | 各题、各分群：模拟均值 − 真实均值 |
| 分布差异 | 各题的总变差距离或 Wasserstein 距离 |
| 方差比 | 模拟的标准差 / 真实的标准差；小于 1 即方差压缩 |
| 题间相关 | 模拟与真实的题间相关矩阵之差；模拟的相关普遍更高，即态度塌缩 |
| 效应量比 | 版本之间的差：模拟 / 真实；大于 1 即效应放大 |

这五项对应 `docs/00` §5 所引研究度量的失真类型。

校准的产物是一张按「场景包 × 分群 × 题」的修正表（均值的平移量、方差的缩放量、效应的缩小系数），用于之后同类实验的结果修正。修正表有适用范围和有效期：人群变了、模型换了、题目改了，都要重做。

**不做的事：** 不用少量真实数据去调提示词直到模拟结果「对上」。那是过拟合，换一个问题就失效。修正放在分析层，提示词与人物保持不变。

### 6.3 命中账本

沿用 v3.0 §11.4：每个进入现实的预测，事后记录命中、漏报、误报，按场景包、分群、人物类别统计。连续漏报的分群，说明人物库里缺了某类人（v3.0 的例子：缺「跨平台兼职」这一类），回到人物工厂补建。

## 7. 评测节奏

| 时机 | 做什么 |
|---|---|
| 每次提交代码 | schema 与样例校验；回放一致性测试（用一份固定的录制重算，结果逐字节比对） |
| 每次实验 | 十二项失真指标；安慰剂与负对照；重复间稳定性 |
| 每批人物入库 | 探针三项指标；人工抽检 |
| 每次改提示词或映射表 | 全库探针重跑；用最近三个已归档实验重跑，比较结论是否改变 |
| 每次换模型 | 同上，另加效度等级重新认定 |
| 每季度 | 人物库健康检查（漂移、过度使用、分群覆盖）；命中账本汇总 |

## 8. 什么不算证据

- 读起来很真实。流畅和准确是两回事。
- 模拟人数很多。见 §2 末。
- 模型自己评价自己的输出「合理」。
- 几个模型结论一致。它们可能有共同的偏差；一致是必要条件，不是充分条件。
- 结论符合委托方的预期。
