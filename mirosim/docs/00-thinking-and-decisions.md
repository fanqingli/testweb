# 00 思路梳理与关键决策

本文回答三件事：这个系统到底在做什么、v3.0 设计里哪些保留哪些要改、每个关键选择为什么这样定。
后面七份文档是它的展开。

## 1. 一句话定义

> 给定一件还没发生的事（一条政策、一版文案、一个定价、一份声明）的几个候选版本，
> 让同一批有长期档案的虚拟人，在互不相通的平行世界里各经历一个版本，
> 比较他们的理解、态度、打算和说法有什么不同，以及这些不同出现在哪类人身上。

三个词各有具体含义：

| 词 | 在本系统里的含义 | 落到实现上 |
|---|---|---|
| 平行 | 方案版本 × 重复次数 × 模型族，构成一张运行矩阵 | 每格是一次独立运行；人物在各格之间互不知情 |
| 推演 | 不是预测一个数，而是比较版本之间的差别，并说明差别从哪来 | 结论的基本单位是「同一个人在 A 与 B 下的差」 |
| 真实 | 不是话说得像，而是分布、差异、稳定性经得起检验 | 一组可计算的指标和四级效度阶梯（`docs/05`） |

## 2. 它能回答什么，不能回答什么

| 能回答（现在就可以用） | 有条件能回答（需要现实数据校准之后） | 不能回答（不应拿它来做） |
|---|---|---|
| 几个版本里哪个更容易被接受、被误读、被反感 | 支持或购买意愿的大致比例区间 | 真实支持率、销量、转化率的点预测 |
| 反对和犹豫集中在哪类人、理由是什么 | 不同人群之间差距的大小 | 取代正式的征求意见、听证或市场调研 |
| 条文或文案里哪句话会被看岔 | 传播会不会起量 | 对具体真人或具体机构的行为预测 |
| 落地后可能出现哪些规避、转嫁、退出行为 | | 依赖视觉、口味、手感的判断（包装、试吃、试用） |
| 正式调研前，问卷该问什么、该找谁问 | | 几个月以上的习惯养成与遗忘 |

第三列写进报告模板的「不适用范围」一节，每份报告都带。

### 3.2 需要补的八处

| # | v3.0 的现状 | 问题 | 本设计的做法 |
|---|---|---|---|
| G1 | 只有会议研讨一种形态 | 营销和品牌预评估问的是「一千个人各自看到后怎么反应」，不是「十个人开会怎么吵」。让消费者开会讨论广告，会系统性地高估关注度和理性程度 | 增加群体反应（panel）和传播（diffusion）两种模式，三种模式共用人物库与分析底座（`docs/01`） |
| G2 | MBTI 只是人物卡上的一个字符串 | 模型拿到四个字母会演成网络上的类型漫画，而且对实际发言行为没有约束力 | 四字母 + 四条连续轴 + 五项补充特质；提示词里不出现类型名，只出现行为描述；发言概率、字数、转发概率、立场变动上限由代码执行（`docs/02`） |
| G3 | 每场结束后自动更新人物成长：karma、`stance_history`、`memory_anchor`（§4.8、§6.5、§6.6）。运行时冻结人物卡快照（§6.4）这一点已经做对 | 快照保住了旧报告，但没解决平行对比：人物带着方案 A 的经历去看方案 B，对比就被污染；复用越多，人物越被实验本身塑造，而不是被他的人生塑造 | 沿用快照；再加上记忆只追加、平行世界分支；实验默认不写记忆，只有现实中真正发生了的那个版本才提交进人物的人生（`docs/02` §5） |
| G4 | 相关方地图选的是「代表」，没有人群的占比与抽样（§4.3） | 研讨会选代表是对的；但要问「多少人会怎样」时，几位代表聚合出的比例没有分母意义 | 人群框架：分群、占比、抽样人数、占比依据；报告同时给按占比加权和不加权的结果（`schemas/population_frame.schema.json`） |
| G5 | 有单变量敏感性实验和联动开关的 A/B（§11.1、§8.8），没有方案之间的对照设计 | 无法区分「版本 B 更好」和「模型这次碰巧更友好」 | 现状对照、安慰剂（同一内容跑两遍）、负对照（明显差的版本）；安慰剂差异是全部结论的噪声底（`docs/03` §6） |
| G6 | 复现的验收是「用清单重放，发言级语义一致率 ≥ 90%」（A1、§11.3） | 把两件不同的事合在一个门槛里：重新调用模型时输出本来就会变，人物温度 0.8–0.9 下能否到 90% 取决于模型而不取决于系统；而分析环节的可复现本应是 100% | 拆成两件事：回放（用录制下来的模型输出重算全部分析，必须逐字节一致）和重跑稳定性（重新调用模型，看结论稳不稳，报告区间）。§11.3 的一致率公式沿用为重跑稳定性的算法（`docs/03` §7） |
| G7 | 没有政策以外的测量工具 | 营销和品牌的问题无处落 | 三个场景包，各有刺激物类型、量表、行为选项和报告结构（`docs/04`） |
| G8 | 有校准闭环与命中账本（§11.4），但报告能下多强的结论与是否校准过无关 | 像不像、稳不稳，都不等于准不准；没校准过的系统照样能输出带小数点的比例 | 沿用校准闭环，再加四级效度阶梯：L2 以上必须有现实数据；每份报告标明所处等级，等级决定允许下什么样的结论（`docs/05` §5） |

另有两点实施层面的说明：v3.0 文档提到的 v2.6 代码不在本次可见范围内，是否复用其代码须在第 0 阶段盘点后决定（`docs/07`）；
v3.0 以 JSON 文件加文件锁为存储（§3.2），在群体反应模式的调用量下（单次实验数千到上万条记录）不够用，改用 SQLite 起步。

## 4. 八个关键决策

**D1 以对比为产出，不以预测为产出。**
大模型模拟人群的绝对水平有已知的系统偏差（见 §5）。同一批人物、同一个模型、同一套提示词下，这些偏差在两个版本上大体同向，相减后抵消一部分，所以版本之间差的**方向和排序**比任何一个版本的绝对水平可靠。
但差的**大小**并不可靠：模拟会放大实验效应（同见 §5）。
所以所有实验至少两个版本，只有一个候选时自动加入现状对照；报告先讲谁高谁低、差在哪类人，校准之前不报差了多少个百分点。

**D2 性格管「怎么反应」，处境管「反应什么」。**
一个配送员对限时规定的立场，主要由收入结构、被罚经历、有没有别的出路决定；MBTI 决定的是他先说还是后说、说长还是说短、看条文还是看大意、当场表态还是先观望。
人物卡因此分成处境（利益、约束、经历、媒介、知识边界）和性格两部分，性格不得直接写出立场。

**D3 MBTI 用作人物的索引和入口，行为由连续分值驱动。**
MBTI 好懂、好沟通，适合给人物库分类和给使用者展示。但它把连续的差异切成两半，而且缺少情绪稳定性这一维——McCrae 与 Costa（1989）用五因素模型重新检视 MBTI 时已指出这两点。
因此：保留四字母作标签；每条轴存 −1 到 1 的连续分值，允许边界型；另加情绪稳定性、风险承受、制度信任、从众、价格敏感五项补充特质。映射表里每一条都是待检验的设计假设（`config/mbti_behavior_map.yaml`）。

**D4 档案与实验隔离。**
人物可以长期复用，前提是实验不改变人物。读记忆永远允许，写记忆默认关闭。详见 `docs/02` §5。

**D5 能由代码决定的，不交给模型。**

| 代码决定 | 模型决定 |
|---|---|
| 抽谁、每类抽多少 | 这个人怎么理解看到的东西 |
| 这个人看没看到、从哪个渠道看到 | 第一反应、态度、理由 |
| 这一轮谁发言、最多说多少字 | 具体怎么说 |
| 转发的话传给谁 | 会不会转、转的时候怎么说 |
| 汇总、加权、检验、排序 | 开放回答的主题归并（带证据回查） |
| 立场变动是否超限 | — |

模型擅长的是在给定身份下生成合乎情理的反应；它不擅长的是保持比例、保持随机、保持克制。

**D6 先广后深的漏斗。**
群体反应模式便宜、覆盖广，用来找出差异在哪；研讨模式贵、细，用来看清差异为什么产生、有没有能谈拢的条件。
标准做法是先跑群体反应，从中挑出态度最分化的分群和最典型的人物，再让他们进入研讨。

**D7 拟真是可检验的指标，不是观感。**
列出十二种已知失真，每种配一个机制去压、一个指标去量（`docs/03` §5）。指标不达标的实验不出报告。

**D8 结论的强度随效度等级走。**
没有现实数据校准之前（L0、L1），只允许下排序和定性的结论，不允许出比例数字作为预测。这条规则由报告生成器强制执行，不靠使用者自觉。

## 5. 依据

本设计对「大模型能在多大程度上模拟人」的判断，来自下列公开研究。引用它们是为了说明哪里可靠、哪里要设防，不是为了证明系统准确。

| 文献 | 与本设计的关系 |
|---|---|
| Park 等，*Generative Agents: Interactive Simulacra of Human Behavior*，UIST 2023，doi:10.1145/3586183.3606763 | 记忆流、检索（相关 × 新近 × 重要）、反思的基本结构。本设计的长期档案沿用这一思路，加上版本与世界分支 |
| Argyle 等，*Out of One, Many: Using Language Models to Simulate Human Samples*，Political Analysis 31(3)，2023，doi:10.1017/pan.2023.2 | 用人口学背景做条件，模型能重现分群体的回答分布。这是「人群框架 + 人物条件化」做法的出发点 |
| Bisbee 等，*Synthetic Replacements for Human Survey Data? The Perils of Large Language Models*，Political Analysis 32(4)，2024，doi:10.1017/pan.2024.5 | 合成样本用于替代问卷数据时的风险。对应本设计的方差检查、多模型族对照和「不出点预测」的规则 |
| Park 等，*AI Simulations Grounded in Rich Self-Reports Increase Accuracy and Reduce Distortion*，arXiv:2411.10109（2026-11-16 版） | 1,052 名美国成年人的两小时访谈。在 GSS 题目上，只用人口学属性的模拟准确率为 60.4%，结合访谈与问卷为 72.8%，受试者本人两周后重测的一致率为 79.5%。文中度量了八种样本层面的失真：均值偏移、方差压缩、分布变形、题目间相关过高、态度塌缩到单一维度、意识形态分选、实验效应放大、过度理性。两点直接进入本设计：人物档案越厚越准（所以做长期档案）；失真可以减轻但消不掉，其中过度理性在经济博弈中没有改善（所以设对照、设效度等级） |
| Horton 等，*Large Language Models as Simulated Economic Agents: What Can We Learn from Homo Silicus?*，arXiv:2301.07543 | 给模型设定禀赋、信息和偏好后重做经济学实验，结果在定性上与原实验相近。支持「看方向和排序」的用法 |
| Li 等，*Determining the Validity of Large Language Models for Automated Perceptual Analysis*，Marketing Science 43(2)，2024，doi:10.1287/mksc.2023.0454 | 用模型做品牌感知分析的效度检验。品牌包的联想与差异度测量参考这一方向 |
| McCrae 与 Costa，*Reinterpreting the Myers-Briggs Type Indicator From the Perspective of the Five-Factor Model of Personality*，Journal of Personality 57(1)，1989，doi:10.1111/j.1467-6494.1989.tb00759.x | D3 的依据 |

上述研究的受试者以美国人群为主。中文语境、国内政策与消费场景下的效度没有现成证据，只能靠本系统自己的校准环节（`docs/05` §6）逐步建立。这是整个设计里最大的未知数。
