## 结论摘要

原方案的四级任务对象、四值分存、证据锚点、分级签署、批量快照、能力包人工审批等骨架设计建议保留。优化集中在五个转变：

| 转变 | 原方案 | 优化后 |
|---|---|---|
| 采集方式 | 上传文件后识别 | 五级通道：接口、在线表单、系统模板回收优先，识别只处理存量与长尾 |
| 模型用法 | 运行期由模型抽值 | 模型只返回源单元格指针，数值由程序读取；高频版式由 Agent 在构建期写成能力包，运行期确定性执行 |
| 人工确认 | 逐项确认，按加权可信度分级 | 按通道与双路一致性分三档；证据必看、关键指标盲录、事后抽检；以入库差错率为最终指标 |
| 留痕 | 可更新的审计表，AI 过程不记录 | 只追加事件流加哈希链与日摘要锚定；AI 运行记录与会话文件归档；可导出离线可验证的溯源包 |
| 智能化 | 固定顺序的识别工序 | 确定性流程编排，Pi 等 Agent 作为受控叶子节点：只读工具加提议工具，有副作用的动作进审批队列 |

实施顺序调整为：先验证（样本、基线、私有模型能力），再交付不依赖 AI 的协同闭环，然后依次叠加原生文件识别、Agent 层、扫描件与管理增强。
